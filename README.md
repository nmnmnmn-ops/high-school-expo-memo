# 高校受験 全公立展メモアプリ

高校受験向け全公立展で、各高校への質問と回答を効率的に記録するスマートフォン用Webアプリです。

## 📋 機能

- **🏫 複数の高校に対応**: 最大5校まで登録可能
- **📝 5つの質問テンプレート**: 事前に考えられた重要な質問項目
- **📊 進捗管理**: 各高校の質問回答状況を一目で確認
- **💾 自動保存**: ブラウザに自動保存（インターネット不要）
- **📥 データ出力**: CSV形式でエクスポート可能
- **📱 モバイル最適化**: スマートフォンで快適に操作

## 🎯 質問テンプレート

1. **ダンス部の活動状況**
   - 週の活動頻度、大会出場、初心者向けか等

2. **学校行事（運動会・文化祭）の力の入れ具合**
   - 規模、準備期間、生徒主体度等

3. **通学について**
   - 最寄駅、所要時間、スクールバス、駐輪場等

4. **設備について**
   - 図書館、自習室、学食、Wi-Fi環境等

5. **進学実績**
   - 大学進学率、主な進学先、推薦枠等

## 🚀 使い方

### 1. アプリを開く
ブラウザで `index.html` をダブルクリック、または以下のURLでアクセス:
```
https://nmnmnmn-ops.github.io/high-school-expo-memo
```

### 2. 学校を追加
- 「新しい学校を追加」セクションに学校名を入力
- 「追加」ボタンをクリック

### 3. 質問に回答
- 各学校カードの質問項目をタップ
- 「編集」ボタンをクリックしてモーダルで回答を入力
- 「保存」をクリック

### 4. データを確認
- 各学校の回答状況を確認
- 進捗バーで完成度を確認

### 5. データを出力
- 「📥 データをダウンロード」ボタンをクリック
- CSVファイルがダウンロードされます
- ExcelやGoogleシートで開いて後で確認可能

### 6. リセット
- 「🗑️ すべてをリセット」でデータをクリア

## 💡 ポイント

- **自動保存**: 入力は自動的にスマホに保存されます
- **オフライン対応**: インターネット接続がなくても動作
- **スマホ最適化**: 全公立展会場でのタップ操作に最適化
- **軽量**: ダウンロード不要、ブラウザだけで動作

## 📱 対応デバイス

- iPhone・iPad
- Android スマートフォン・タブレット
- Windows/Mac のブラウザ

## 🔒 プライバシー

すべてのデータはあなたのスマートフォン上に保存され、外部のサーバーに送信されません。

## 💻 技術

- **HTML5**: アプリの構造
- **CSS3**: レスポンシブデザイン
- **JavaScript**: ロジックとデータ管理
- **LocalStorage API**: データ永続化

## 📝 カスタマイズ

### 質問項目を変更する場合

`app.js` の以下の部分を編集:

```javascript
const QUESTIONS = [
    { id: 'dance', label: 'ダンス部の活動状況' },
    { id: 'events', label: '学校行事（運動会・文化祭）の力の入れ具合' },
    // ...
];
```

### 最大登録校数を変更する場合

`app.js` の以下を編集:

```javascript
const MAX_SCHOOLS = 5; // 好きな数に変更
```

## 📞 トラブルシューティング

### データが消えた場合
- ブラウザのキャッシュをクリアしていないか確認
- 別のブラウザで試してみてください

### ダウンロードできない場合
- ブラウザのポップアップブロック設定を確認
- ダウンロードフォルダの権限を確認
